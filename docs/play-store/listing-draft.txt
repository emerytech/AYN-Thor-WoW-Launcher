Short description: Controller-friendly launcher for your compatible ARM64 game installation.

Bring your own compatible Windows ARM64 game files to an Android handheld.
Import a complete authorized installation through Android's folder picker, configure
controller-friendly controls and launch through the bundled runtime.

Features:
- Touch and physical controller input, including dual-screen handheld controls.
- Optional frame generation using your own compatible Lossless.dll.
- Optional encrypted local saved login and explicit fill/copy actions.
- A setting to keep the game running when launcher menus are open.

Game files and Lossless.dll are not included. Game access and compatibility vary.
Importing copies the selected installation and requires additional free space.
Uninstalling removes the imported copy and app settings. Android 10+ and ARM64 required.
The bundled graphics-driver paths require compatible Qualcomm Adreno hardware.
AYN Thor is the tested handheld; other hardware is not verified.
